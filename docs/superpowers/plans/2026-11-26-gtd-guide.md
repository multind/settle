# 安顿 Settle「GTD 使用指南分层提示」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-subagent-driven-development (recommended) or superpowers-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为安顿 Settle 引入「GTD 使用指南分层提示」三单元——① **PageRuleHint**（10 页页级空态从单行文案等位替换为「图标 + 纪律标题 + 纪律正文」复用组件）；② **OnboardingCard**（首启引导卡，三条铁律 + 每日动作 + 跳完整指南，经 SharedPreferences bool key `gtd_guide_seen` 关闭后不再出现）；③ **GtdGuidePage**（完整指南页，作为侧边栏第 12 个导航目的地 index 11，四分区）。全部文案走 l10n 中英双语（新增 45 key / 删除 5 key / 净增 40），视觉遵循既有 Things 3 极简规范（纯底 + 1px hairline + 圆角 8，零阴影）。

**Architecture:** 三单元同归新建 feature 模块 `lib/features/guide/`（与 inbox/today 等 feature 并列）；PageRuleHint 为 `Center(child: Text(...))` 的**等位替换**（结构不变、布局风险最低）；OnboardingCard 以外壳 `_pageColumn()` **in-flow 布局**挂载于内容列顶部（页面 AppBar 之上），从结构上杜绝遮挡 FAB/底部导航；指南页导航为 `_navSpecs` **仅追加 index 11**（设置之后，`inMore: true`、`collectFab: false`、无快捷键），`_digitKeys` 派生逻辑与 Ctrl+0/1..9 语义零变化。

**Tech Stack:** Flutter/Dart、drift、shared_preferences（沿用 `locale` 读写模式，新增 1 个 bool key，无新表/无迁移/无新依赖）、flutter gen-l10n。

```dart
import 'package:flutter/material.dart';
import 'package:settle_app/app/theme.dart';

/// 页级空态规则提示（GTD 使用指南单元一）：图标 + 纪律标题 + 纪律正文。
/// 各页把既有 `Center(child: Text(l10n.xxxEmpty))` 等位替换为
/// `Center(child: PageRuleHint(icon: …, title: …, message: …))`
/// （结构不变、布局风险最低）。文案由页面以 l10n 已解析字符串传入。
class PageRuleHint extends StatelessWidget {
  const PageRuleHint({
    super.key,
    required this.icon,
    required this.title,
    required this.message,
  });

  /// 页面图标（复用导航图标，与侧边栏视觉一致）。
  final IconData icon;

  /// 纪律标题（l10n 已解析字符串，页面传入）。
  final String title;

  /// 纪律正文（l10n 已解析字符串，页面传入）。
  final String message;

  @override
  Widget build(BuildContext context) {
    final isLight = Theme.of(context).brightness == Brightness.light;
    final tokens = isLight ? AppTokens.light : AppTokens.dark;
    return ConstrainedBox(
      key: const Key('page_rule_hint'),
      constraints: const BoxConstraints(maxWidth: 340),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(icon, size: 40, color: tokens.muted),
          const SizedBox(height: 12),
          Text(
            title,
            textAlign: TextAlign.center,
            style: TextStyle(
              fontSize: 15,
              fontWeight: FontWeight.w600,
              color: tokens.text,
            ),
          ),
          const SizedBox(height: 6),
          Text(
            message,
            textAlign: TextAlign.center,
            style: TextStyle(fontSize: 13, color: tokens.muted),
          ),
        ],
      ),
    );
  }
}
```
