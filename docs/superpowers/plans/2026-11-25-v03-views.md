# v0.3 视图层实施计划（今日改造 + 随时/即将/日志 + 导航重组）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-subagent-driven-development (recommended) or superpowers-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 导航重组（侧边栏 11 项三组 + 底部 5 项时间优先）+ 今日改造（逾期置顶）+ 随时/即将/日志三新页。视图语义按用户确认模型：有日期按日期走，无日期进随时，完成进日志。

**Architecture:** 响应式外壳索引表 `[0..10]`；宽屏自定义可滚动分组侧边栏（替换 NavigationRail）；窄屏底部 5 项 + 「更多」BottomSheet；各页用数据层新查询 `watchToday/watchAnytime/watchUpcoming/watchDone`。任务行暂沿用既有简单行（公共 TaskListView 由交互计划统一引入，本计划不重复造组件）。

**Tech Stack:** Flutter、Material、Riverpod。

**Spec:** `docs/superpowers/specs/2026-11-25-v03-views-design.md`
