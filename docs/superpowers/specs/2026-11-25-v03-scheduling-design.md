# v0.3 调度系统设计（时间粒度 + 重复规则 + 应用内提醒）

日期：2026-11-25
状态：已批准（v0.3 设计定稿用户确认，本 spec 为其调度部分）
依赖：数据层 spec——`repeatRule`/`reminderAt` 字段、`RepeatRule.nextDate`、
`complete()` 事务内生成下一次；视图 spec——视图按日期落位
前置：HEAD `627425c`，工作区干净

## 1. 背景与目标

调度系统边界（用户确认）：**①时间粒度 ②重复规则 ③应用内提醒**（运行时弹提示，
不保证系统级通知——符合主规格 §2 非目标「提醒依赖用户在应用内查看」）。

## 2. 时间粒度：date → date+time

`TaskFormFields` 的截止/开始日期选择器升级为**日期+时间**：

- 交互：`showDatePicker` 选日期 → `showTimePicker` 选时间（默认 09:00）；
  已有日期时直接选日期保留原时间
- 展示：`yyyy-MM-dd HH:mm`（12/24 小时制跟随系统 locale）
- **新增「清除」按钮**（当前只有选择无清除，补上）：截止/开始/提醒均可清除
- `TaskDraft` 不变（`DateTime?` 已支持时间），落库 ms epoch

## 3. 重复规则（每日/每周/每月/每 N 天）

### 3.1 表单（TaskFormFields 新增）

- 下拉「重复」：无 / 每日 / 每周 / 每月 / 每 N 天
- 「每 N 天」选中时出现 N 输入框（1-365 正整数校验）
- 存 `repeatRule` 字符串：`null` | `daily` | `weekly` | `monthly` | `every:N`

### 3.2 完成时生成下一次（数据层已定义，此处确认 UI 联动）

- 完成重复任务 → 原任务进日志 + 新副本按规则推进日期自动出现（今日/即将）
- 新副本同时克隆标签/项目/情境/精力/优先级，并推进提醒时间
- 生成瞬间用户可见：新副本出现在对应视图顶部区域（按 sortOrder 自然落位）

### 3.3 展示

- 任务行副标题可显示重复徽标（`↻ 每周`），`muted` 小字——帮助识别"会回来的任务"
- 编辑对话框重复下拉预填当前值

## 4. 应用内提醒（运行时到点弹提示）

### 4.1 表单

- 新增「提醒」行：date+time 选择器 + 清除按钮，存 `reminderAt`

### 4.2 运行时服务（新增 `ReminderService`）

- 由响应式外壳启动（`initState` 创建，随 shell 生命周期）：
  - `Timer.periodic(30s)` 轮询
  - 每轮：查 `reminderAt ≤ now && reminderAt > 上一轮时间 && status != done`
    且**本会话未通知过**（内存 `Set<int> notifiedIds`）的任务
  - 命中 → 顶部 `MaterialBanner`（或 SnackBar）：「提醒：任务标题」
    + 按钮 [打开]（弹出该任务编辑对话框）/ [知道了]（关闭并标记已通知）
- 内存态即可（重启重来，符合"应用内"边界）；完成任务后 `status!=done` 自然不再触发
- 同一时刻多个提醒：逐个排队展示（Banner 依次显示或合并为一条汇总）

### 4.3 边界声明

- 应用未运行 / 后台不保证提醒（非目标）
- 不做系统通知插件接入
