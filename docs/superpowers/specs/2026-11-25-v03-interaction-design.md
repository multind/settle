## 1. 背景与目标

交互层范围（用户确认全做）：**列表内拖拽重排 + 即将视图拖到日期 + 多选批量 +
桌面键盘快捷键**；明确**不做跨区拖拽**（拖到项目/情境）。

## 2. 公共任务列表组件（`lib/features/task/task_list_view.dart`）

今日/随时/即将/等待/将来也许/日志 六处任务列表收敛为公共组件，统一支持：
- **重排**（`reorderEnabled`）：`ReorderableListView`，onReorder →
  `repository.reorder(新顺序 id 列表)`（落库 sortOrder）
- **多选**（`selectionEnabled`）：长按进入选择模式；行前出现勾选圈，点选切换；
  顶栏变「已选 N 项」+ 操作按钮 + 退出（X）
- **焦点行**（`focusEnabled`，桌面）：J/K 移动高亮行，供快捷键 Enter/Delete
  操作（见 §5）
- 重排与多选互斥（重排模式禁止长按进多选，反之亦然），避免手势冲突

视图用公共组件时各自声明启用项：

| 视图 | 重排 | 多选 | 焦点 |
|---|---|---|---|
| 今日 | ✅ | ✅ | ✅ |
| 随时 | ✅ | ✅ | ✅ |
| 即将 | 组内重排 | ✅ | ✅ |
| 项目卡片任务列表 | ✅ | ✅ | ✅ |
| 等待/将来也许 | 可选 | ✅ | ✅ |
| 日志 | ❌ | ✅（恢复/删除） | ✅ |

## 3. 拖拽重排

- 今日/随时/项目卡片任务列表开启重排；即将支持组内重排（跨日期组不做，
  改日期用拖到日期头）
- 重排结果实时落库 `sortOrder`（事务），刷新后顺序保持
- 桌面鼠标拖动 + 触屏长按拖动均支持（ReorderableListView 内建）

## 4. 拖到日期（即将视图）

- 即将的行包 `Draggable<int>(taskId)`；日期分组头包 `DragTarget<int>`
- 拖到某日期头 → `repository.setScheduled(id, 该日)`（写 scheduled，清掉？——
  不清 dueDate，仅安排开始日）；任务即时移到该日期组（或若日期已过/今天则按
  Today 语义落入今日）
- 落点高亮反馈（日期头描边变 primary）

## 5. 键盘快捷键（桌面，输入框聚焦时禁用）

| 键 | 动作 |
|---|---|
| `N` | 打开全局收集对话框 |
| `Ctrl/Cmd+1..9` | 切到侧边栏第 1..9 项（收件箱..日志） |
| `Ctrl/Cmd+0` | 切到回顾（index 9） |
| `J` / `K` | 焦点行下移 / 上移（当前列表内循环） |
| `Enter` | 完成焦点行任务（done） |
| `Delete` | 删除焦点行任务（确认对话框） |

- 实现：shell 层 `Shortcuts/Actions/Intent`（N + 视图切换）；列表组件内
  `FocusScope` 管理焦点行（桌面 `focusEnabled`）
- 文本输入焦点（表单/搜索框）时全局快捷键不拦截（`FocusManager` 检查）
- 平台判断 `kIsWeb || Platform.isWindows` 等桌面平台启用；触屏窄屏不启用 J/K

## 6. 多选批量操作

进入选择模式后顶栏操作按钮（按视图裁剪）：

| 操作 | 行为 | 适用 |
|---|---|---|
| 完成 | 批量 `complete`（重复任务各自生成下一次） | 今日/随时/即将/等待/将来也许 |
| 删除 | 确认对话框 → 批量硬删除 | 全部（日志=删除归档） |
| 设日期 | 对话框（截止/开始 二选一 + 日期）→ 批量写 | 今日/随时/即将/等待/将来也许 |
| 移动 | 项目下拉 → 批量写 projectId | 今日/随时/即将/等待/将来也许 |
| 恢复 | 批量 reopen | 日志 |

- 退出选择模式：顶栏 X / Esc / 全部取消选中
